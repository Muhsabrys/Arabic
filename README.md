# Al-Manara | Arabic Learning Hub 🕌

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![HTML5](https://img.shields.io/badge/HTML-5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38B2AC?logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

**Al-Manara** (المنارة - The Lighthouse) is a comprehensive, interactive Arabic language learning website designed to guide learners from beginner to advanced levels.

## 🌟 Features

- **10 Learning Modules**: Vocabulary, Grammar, Phonics, Culture, Quizzes, Reading, Writing, Listening, Speaking, and Games
- **100 Structured Lessons**: Each module contains 10 carefully crafted lessons
- **Beautiful UI**: Designed with Tailwind CSS using an elegant Emerald Green and Gold color scheme
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Design**: Engaging cards, animations, and hover effects
- **Cultural Integration**: Learn language alongside Arab culture and traditions
- **Progressive Learning**: Lessons build upon each other from Beginner to Mastery level

## 📚 Module Overview

### 1. **Vocabulary** (مفردات)
Learn 200+ essential Arabic words organized by themes like greetings, family, numbers, colors, food, and more.

### 2. **Grammar** (قواعد)
Master Arabic grammar including alphabet, pronouns, verb conjugations, sentence structure, and more.

### 3. **Phonics** (أصوات)
Perfect your pronunciation with lessons on Arabic sounds, vowels, and reading rules.

### 4. **Culture** (ثقافة)
Explore Arab culture, traditions, cuisine, arts, and contemporary society.

### 5. **Quizzes** (اختبارات)
Test your knowledge with interactive quizzes and comprehensive assessments.

### 6. **Reading** (قراءة)
Enhance comprehension with stories, dialogues, articles, and classical literature.

### 7. **Writing** (كتابة)
Practice Arabic script from basic letter formation to advanced composition.

### 8. **Listening** (استماع)
Train your ear with audio lessons and listening comprehension exercises.

### 9. **Speaking** (محادثة)
Build confidence with pronunciation practice and conversation scenarios.

### 10. **Games** (ألعاب)
Learn through fun interactive educational games and activities.

## 🚀 Getting Started

### View Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Muhsabrys/Arabic.git
   cd Arabic
   ```

2. Open `index.html` in your web browser:
   ```bash
   open index.html  # macOS
   # or
   start index.html  # Windows
   # or
   xdg-open index.html  # Linux
   ```

### Deploy to GitHub Pages

1. Push to GitHub (if not already done)
2. Go to your repository Settings
3. Navigate to "Pages" section
4. Under "Source", select your main branch
5. Your site will be available at: `https://Muhsabrys.github.io/Arabic`
